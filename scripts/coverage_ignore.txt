# Archivos que quedan fuera del cálculo de cobertura.
#
# Cada línea es un patrón de expresiones regulares que se matchea contra la
# ruta del archivo dentro del profile de `go tool cover` (ej. `cmd/server/main.go`).
# Las líneas vacías y las que empiezan con `#` se ignoran.
#
# Solo deben agregarse aquí archivos que NO PUEDEN testearse por diseño:
#
# cmd/server/main.go — entrypoint del binario (package main). `main()` orquesta
# la configuración, la conexión, las señales y el shutdown; no puede importarse
# desde un test ni aislarse sin refactorizaciones forzadas. Ya no contiene SQL:
# las migraciones viven en migrations/*.sql y las ejecuta golang-migrate.
^cmd/server/main\.go
#
# internal/service/mailer.go — las funciones del smtpMailer (SendVerificacion,
# dialSMTPS, dialSMTPStartTLS) abren conexiones TCP + TLS + protocolo SMTP real.
# Solo se testea el path de logMailer (modo dev) en unit/integration.
^internal/service/mailer\.go
#
# web/embed.go — los paths de panic dentro de TemplateFS/StaticFS/ImagesFS son
# defensas contra un fallo de fs.Sub en los //go:embed; son garantías de
# compilación que nunca se ejecutan en runtime.
^web/embed\.go
